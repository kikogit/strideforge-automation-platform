# StrideForge Automation Platform

Enterprise-grade automation framework platform using Python, Pytest, Playwright, Docker, and Git.

## Framework Projects

- common-utilities-framework
- ui-core-framework
- api-core-framework
- mobile-core-framework

## Test Projects

- UI tests
- API tests
- Mobile tests

## Current Branching Strategy

- main: stable branch
- develop: active development branch
- feature/*: feature development branches

## Local Setup

Python virtual environment is created at the repository root.

## Test Runner

Pytest is the standard test runner for all teams.
